## 一、技术选型与依赖

### 1.1 核心依赖

| 包名 | 版本 | 用途 | 是否必须 |
|------|------|------|---------|
| Python | >=3.10 | 运行时 | 必须 |
| litellm | >=1.0 | 统一 LLM API 调用 | 必须 |
| pydantic | >=2.0 | 数据模型定义与校验 | 必须 |
| click | >=8.0 | CLI 框架 | 必须 |
| rich | >=13.0 | CLI 美化输出 | 必须 |
| pyyaml | >=6.0 | 配置文件解析 | 必须 |
| jinja2 | >=3.1 | Prompt 模板渲染 | 必须 |
| chardet | >=5.0 | 文本编码检测 | 必须 |
| ebooklib | >=0.18 | EPUB 解析 | 可选 |
| pymupdf | >=1.23 | PDF 解析 | 可选 |
| gradio | >=4.0 | Web UI | 可选 |
| chromadb | >=0.4 | 向量检索（实体消歧） | 可选 |
| deepface | >=0.0.90 | 面部相似度验证 | 可选（生图时） |
| httpx | >=0.25 | HTTP 客户端（调用生图后端） | 可选（生图时） |
| pillow | >=10.0 | 图片处理 | 可选（生图时） |

### 1.2 LLM 选型矩阵

| 用途 | 推荐模型 | 备选模型 | 最低要求 |
|------|---------|---------|---------|
| 世界观分析 | DeepSeek-V3 | Qwen-Max, GPT-4o | 中文理解强，支持 JSON 输出 |
| 实体提取 | DeepSeek-V3 | Qwen-Plus, GLM-4-Plus | 中文理解强，支持长文本 |
| 提示词生成 | DeepSeek-V3 | Qwen-Max, GPT-4o | 中英双语，视觉艺术知识 |
| 图片验证 | Qwen-VL-Plus | GPT-4o, GLM-4V | 多模态理解能力 |

### 1.3 生图后端选型

| 后端 | 模型 | 面部一致性方案 | 显存需求 | 适用场景 |
|------|------|--------------|---------|---------|
| **ChatGPT2API** | gpt-image-2 | edit_image 图片编辑 | 无（本地反代） | **主要后端**，无需GPU |
| ComfyUI | SDXL / FLUX.1 | IP-Adapter FaceID | 8-16GB | 本地 GPU 用户 |
| SD WebUI | SDXL | IP-Adapter FaceID | 8-12GB | SD 老用户 |

### 3.2 Pydantic 模型定义

```python
from enum import Enum
from datetime import datetime
from pydantic import BaseModel, Field


class EntityType(str, Enum):
    CHARACTER = "character"
    SCENE = "scene"
    ITEM = "item"
    CREATURE = "creature"


class ProjectStatus(str, Enum):
    CREATED = "created"
    WORLD_BIBLE_DONE = "world_bible_done"
    EXTRACTING = "extracting"
    EXTRACT_DONE = "extract_done"
    PROMPTING = "prompting"
    PROMPT_DONE = "prompt_done"
    ILLUSTRATING = "illustrating"
    COMPLETED = "completed"
    FAILED = "failed"


class WorldFramework(BaseModel):
    genre: str
    sub_genre: str
    era_setting: str
    technology_level: str
    power_system: str
    social_structure: str
    geography_overview: str
    key_concepts: list[str] = []
    tone_and_mood: str = ""


class ColorPalette(BaseModel):
    primary: str
    secondary: str
    accent: str
    mood: str
    specific_colors: list[str] = []


class VisualAnchoring(BaseModel):
    art_style: str
    art_style_en: str
    color_palette: ColorPalette
    lighting_style: str
    texture_style: str
    atmosphere_keywords: list[str] = []
    atmosphere_keywords_en: list[str] = []
    forbidden_elements: list[str] = []


class CharacterVisualRules(BaseModel):
    face_style: str
    face_style_en: str
    body_proportion: str
    clothing_system: str
    clothing_materials: str
    hair_style_rules: str
    accessory_rules: str


class SceneVisualRules(BaseModel):
    architecture_style: str
    landscape_style: str
    interior_style: str
    weather_patterns: str


class ItemVisualRules(BaseModel):
    weapon_style: str
    material_system: str
    craftsmanship: str


class WorldBible(BaseModel):
    id: str
    project_id: str
    novel_title: str
    world_framework: WorldFramework
    visual_anchoring: VisualAnchoring
    character_visual_rules: CharacterVisualRules
    scene_visual_rules: SceneVisualRules
    item_visual_rules: ItemVisualRules
    created_at: datetime = Field(default_factory=datetime.now)
    updated_at: datetime = Field(default_factory=datetime.now)


class Appearance(BaseModel):
    face: str = ""
    hair: str = ""
    body: str = ""
    distinguishing_features: str = ""


class ClothingVariation(BaseModel):
    context: str
    description: str


class Clothing(BaseModel):
    default: str
    variations: list[ClothingVariation] = []


class Relationship(BaseModel):
    target: str
    relation: str
    name: str = ""


class SourceQuote(BaseModel):
    chapter: int
    text: str
    location: str


class WorldBinding(BaseModel):
    genre: str = ""
    era: str = ""
    face_style: str = ""
    clothing_system: str = ""
    art_style: str = ""


class CharacterAttributes(BaseModel):
    gender: str = ""
    age_range: str = ""
    appearance: Appearance = Appearance()
    clothing: Clothing = Clothing(default="")
    personality: str = ""
    abilities: list[str] = []
    relationships: list[Relationship] = []


class SceneAttributes(BaseModel):
    environment_type: str = ""
    time_of_day: str = ""
    weather: str = ""
    visual_description: str = ""
    atmosphere: str = ""
    key_landmarks: list[str] = []
    color_palette: str = ""


class ItemAttributes(BaseModel):
    category: str = ""
    visual_description: str = ""
    material: str = ""
    size: str = ""
    special_effects: str = ""
    owner: str = ""


class Entity(BaseModel):
    id: str
    project_id: str
    name: str
    aliases: list[str] = []
    type: EntityType
    world_binding: WorldBinding = WorldBinding()
    attributes: dict = {}
    source_quotes: list[SourceQuote] = []
    first_appearance_chapter: int | None = None
    first_appearance_paragraph: int | None = None
    created_at: datetime = Field(default_factory=datetime.now)
    updated_at: datetime = Field(default_factory=datetime.now)


class PromptParameters(BaseModel):
    aspect_ratio: str = "1:1"
    steps: int = 30
    cfg_scale: float = 7.0
    sampler: str = "DPM++ 2M Karras"
    denoising_strength: float | None = None


class Prompt(BaseModel):
    id: str
    entity_id: str
    type: str
    world_prefix_chinese: str = ""
    world_prefix_english: str = ""
    face_block_chinese: str = ""
    face_block_english: str = ""
    chinese_prompt: str = ""
    english_prompt: str = ""
    negative_prompt: str = ""
    style_tags: list[str] = []
    parameters: PromptParameters = PromptParameters()
    source_quotes: list[SourceQuote] = []
    created_at: datetime = Field(default_factory=datetime.now)


class FaceAnchor(BaseModel):
    id: str
    prompt_id: str
    entity_id: str
    image_path: str = ""
    face_embedding: list[float] = []
    quality_score: float = 0.0
    created_at: datetime = Field(default_factory=datetime.now)


class Relation(BaseModel):
    id: str
    project_id: str
    source_id: str
    target_id: str
    relation_type: str
    evidence: str = ""


class Chapter(BaseModel):
    id: str
    project_id: str
    number: int
    title: str = ""
    text: str = ""
    is_processed: bool = False


class Project(BaseModel):
    id: str
    novel_title: str
    input_path: str
    status: ProjectStatus = ProjectStatus.CREATED
    world_bible_id: str | None = None
    created_at: datetime = Field(default_factory=datetime.now)
    updated_at: datetime = Field(default_factory=datetime.now)
```

### 3.3 存储方案

| 数据 | 存储方式 | 文件/表 | 说明 |
|------|---------|---------|------|
| 项目元信息 | JSON | `meta.json` | 项目配置与状态 |
| WorldBible | JSON | `world_bible.json` | 完整世界观锚定文档 |
| 章节文本 | JSON | `chapters/ch_{num}.json` | 逐章保存 |
| 实体档案 | JSON | `entities/{type}_{id}.json` | 逐实体保存 |
| 提示词 | JSON + MD | `prompts/{type}_{id}.json` + `.md` | 双格式输出 |
| 关系数据 | JSON | `entities/relations.json` | 所有关系统一保存 |
| 面部锚定图 | PNG | `face_anchors/{id}.png` | 图片文件 |
| 角色参考图 | PNG | `characters/{id}.png` | 图片文件 |
| 场景背景图 | PNG | `scenes/{id}.png` | 图片文件 |
| 完整插图 | PNG | `illustrations/{id}.png` | 图片文件 |

> 不使用 SQLite，全部采用 JSON 文件存储，简化个人开发复杂度。
> 如后续需要查询性能，可迁移至 SQLite。

#### 4.2.2 ChatGPT2API 后端（主要后端）

- 服务地址：`http://localhost:3000`

| 接口 | 方法 | 用途 | 面部一致性 |

## 六、错误处理

### 6.1 错误码体系

| 错误码 | 范围 | 说明 |
|--------|------|------|
| E1xxx | 1000-1999 | 文件与预处理错误 |
| E2xxx | 2000-2999 | LLM 调用错误 |
| E3xxx | 3000-3999 | 实体提取错误 |
| E4xxx | 4000-4999 | 提示词生成错误 |
| E5xxx | 5000-5999 | 生图错误 |
| E6xxx | 6000-6999 | 配置错误 |

### 6.2 常见错误与处理

| 错误码 | 错误信息 | 原因 | 处理方式 |
|--------|---------|------|---------|
| E1001 | 文件编码无法识别 | 文件使用罕见编码 | 提示用户手动指定编码 |
| E1002 | 章节识别失败 | 无标准章节格式 | 使用滑动窗口切分 |
| E2001 | LLM API 调用超时 | 网络问题或模型过载 | 自动重试 3 次，指数退避 |
| E2002 | LLM 输出格式错误 | 模型未按 JSON 格式输出 | 重新请求，加强 System Prompt |
| E2003 | LLM API Key 无效 | Key 过期或错误 | 提示用户检查配置 |
| E2004 | Token 超限 | 单次输入过长 | 自动切分后重试 |
| E3001 | 实体提取为空 | 章节无实质内容 | 跳过该章节，记录日志 |
| E3002 | 消歧置信度过低 | 无法判断是否同一实体 | 保留为独立实体，标记待确认 |
| E5001 | 生图后端不可用 | ComfyUI/SD 未启动 | 提示用户启动后端 |
| E5002 | 面部相似度不达标 | 生成图面部与锚定图不一致 | 自动重试，调整权重 |
| E5003 | GPU 显存不足 | 模型过大 | 建议降低分辨率或换模型 |

### 7.2 进度追踪

```python
class ProgressTracker:
    def __init__(self):
        self.stages = {
            "world_bible": {"total": 1, "done": 0},
            "preprocess": {"total": 1, "done": 0},
            "extract": {"total": 0, "done": 0},
            "merge": {"total": 0, "done": 0},
            "attribute": {"total": 0, "done": 0},
            "prompt": {"total": 0, "done": 0},
            "illustrate": {"total": 0, "done": 0},
        }

    def update(self, stage: str, done: int = 1):
        self.stages[stage]["done"] += done

    def get_progress(self) -> dict:
        total = sum(s["total"] for s in self.stages.values())
        done = sum(s["done"] for s in self.stages.values())
        return {"total": total, "done": done, "percent": done / total * 100 if total else 0}
```
